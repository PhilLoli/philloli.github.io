# Веб-страница из Figma — Мастеров Иван, QA Engineer

Адаптивная HTML/CSS/JS-реализация макета Figma. Без сборщика и зависимостей JavaScript.

## Как открыть

Откройте `index.html` в браузере. Меню и вкладки Hard Skills работают на JavaScript, карточки обучения раскрываются по нажатию.

## Важно про изображения

Из-за ограничения сети рабочего окружения исходные Figma-изображения нельзя было включить в этот архив как локальные файлы. Страница автоматически пытается найти картинки в папке `assets/`, а если их нет — отображает оригинальные фотографии по **временным ссылкам Figma**. Эти ссылки истекают примерно через 7 дней.

Чтобы сделать сайт полностью автономным, запустите `bash download-assets.sh` **на своём компьютере с интернетом** как можно скорее. Скрипт сохранит фотографии и другие изображения в `assets/` и сайт больше не будет зависеть от Figma. Если ссылки уже истекли, экспортируйте ассеты из исходного Figma-файла и сохраните их под именами, указанными в `script.js`.

## Публикация

Загрузите содержимое папки на GitHub Pages, Netlify, Vercel или любой статический хостинг. Для продакшена обязательно положите файлы изображений в `assets/`.
